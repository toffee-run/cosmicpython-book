# Architecture Patterns with Python — учим Python и технический английский

Неофициальный читатель книги **Architecture Patterns with Python** (известной как
**Cosmic Python**) для русскоязычных разработчиков. Читайте о проектировании
Python-приложений, DDD, TDD и архитектурных паттернах, а при наведении на английское
слово смотрите русский перевод. Так можно разбирать профессиональный текст и заодно
пополнять словарный запас технического английского.

Перевод показывается прямо в тексте, с учётом регистра и контекста, а оригинальная
страница остаётся доступной для чтения. В проекте есть тёмная тема, заметки автора,
адаптация для телефонов и статическая сборка для GitHub Pages или Nginx.

**Стек:** TanStack Start, React, TypeScript, pnpm. Перевод работает локально,
без API-ключей и стороннего сервиса.

> Независимый учебный проект, не связанный с авторами или издателем. Сведения об
> источниках и лицензиях отдельных материалов — в [content/SOURCES.md](content/SOURCES.md).

## Для читателей

Откройте [предисловие](https://toffee-run.github.io/cosmicpython-book/) после
включения GitHub Pages в настройках репозитория. Используйте указатель содержания,
чтобы читать главы по порядку, или наведите курсор на незнакомое слово. На телефоне
перевод переключается касанием.

## Для разработчиков

Сайт собран на TanStack Start, React и TypeScript. Исходные английские главы,
иллюстрации и структура навигации сохранены; маршрут `/` открывает предисловие.

## Запуск

Node.js 22.12+ (в CI используется 24), pnpm 12.3.4 (версия закреплена в `packageManager`).

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Открыть http://localhost:3000/.

При наведении русский перевод показывается прямо на месте английского слова.
Перевод занимает место в строке: соседние слова сдвигаются и при необходимости
переносятся. Рядом с переводом оставляется место для видимого курсора: обычно
ширина исходного слова плюс 24 px. В ссылках с выравниванием вправо отступ
переносится на другую сторону; положение проверяется после переноса строк.
Если по горизонтали места недостаточно, перевод переносится ниже курсора.
При уходе с исходной области
слова, прокрутке или Escape возвращается оригинальный текст и его разметка.
На сенсорном экране перевод переключается касанием. Кодовые блоки и inline-код
не переводятся. Чтение и переходы работают даже без JavaScript; перевод требует JS.

Регистр сохраняется: `domain` → «предметная область», `Domain` → «Предметная область»,
`DOMAIN` → «ПРЕДМЕТНАЯ ОБЛАСТЬ» (конкретный перевод также зависит от фразы).

Переключатель темы расположен справа внизу. До ручного выбора используется тема
операционной системы; выбранная тема сохраняется между страницами и перезагрузками.

Контекст учитывается через локальные правила для фраз и отдельных фрагментов.
Например, `order` в `in order to` и в `an order` переводится по-разному.
Для фраз без правила остаётся словарный перевод: это не нейросетевой перевод
всех предложений, и редкие значения могут потребовать правки.

## Правка текстов, заметок и переводов

| Файл | Назначение |
| --- | --- |
| `content/book/*.html` | Исходные главы: текст, заголовки, разметка |
| `content/customizations.mjs` | Собственные заметки, замены и переводы по главам |
| `content/translations/overrides.json` | Общие переводы и техническая терминология |
| `content/translations/phrases.json` | Переводы слов внутри устойчивых выражений |
| `content/translations/dictionary.json` | Базовый словарь FreeDict, используемый книгой |
| `public/images/` | Иллюстрации |

Например, в `content/customizations.mjs`:

```js
export default {
  chapter_01_domain_model: {
    replacements: [
      {
        selector: '#_what_is_a_domain_model + .paragraph p',
        text: 'Your own paragraph about domain models.',
      },
    ],
    notes: [
      {
        after: '#_what_is_a_domain_model',
        title: 'Моя заметка',
        html: '<p>Модель описывает правила предметной области.</p>',
      },
    ],
    translations: { domain: 'домен', model: 'модель' },
    phrases: { 'domain model': { domain: 'предметной области' } },
    contexts: [
      {
        selector: '#_what_is_a_domain_model',
        translations: { domain: 'предметной области' },
      },
    ],
  },
}
```

Селектор должен выбирать ровно один элемент: иначе сборка выдаст ошибку.
Вместо `text` можно использовать `html`. Это доверенный HTML автора проекта.
Русские заметки не разбиваются на слова. Атрибут `data-no-translate` отключает
перевод внутри выбранного элемента.

Приоритет: перевод конкретного фрагмента (`contexts`) → самое длинное совпавшее
выражение → словарь главы → `overrides.json` → базовый словарь. `phrases` главы
заменяют одноимённые глобальные фразы; у `contexts` также может быть свой `phrases`.
Фразы распознаются через вложенные `<em>`/`<strong>`, но не через границы предложений.
Каждое вхождение проверяется отдельно, поэтому одно слово может иметь разные
переводы в одном абзаце. Ключи — английские
слова в нижнем регистре; значения — русский текст. Словоформы задаются отдельными
ключами. Новые слова без словарной статьи сохраняют английский текст; их список
и частоты появляются после сборки в `src/generated/translation-report.json`.
`pnpm test` проверяет полное покрытие словаря. При добавлении нового текста
добавьте недостающие переводы в `overrides.json`.

Dev-сервер пересобирает главы после изменения `content/`. При добавлении главы
добавьте её HTML и ссылку в `#toc` файла `content/book/preface.html` — это источник
списка страниц. Остальные оглавления находятся в HTML глав.

## Статическая сборка

```sh
pnpm build
pnpm preview
```

Предпросмотр: http://localhost:4173/. Это обычный файловый HTTP-сервер,
без SSR и SPA-fallback. Для хостинга нужен **только `dist/client/`**: HTML всех
страниц, JS, CSS, шрифты и изображения. `dist/server/` используется TanStack Start
только при prerendering и на хостинг не загружается.

Для Nginx скопируйте `dist/client/` в web root; пример — `nginx.conf.example`.
Устанавливать Nginx на машину разработки не нужно.

### GitHub Pages и другие подпапки

```sh
BASE_PATH=/cosmicpython-book/ pnpm build
BASE_PATH=/cosmicpython-book/ pnpm preview
```

Открыть http://localhost:4173/cosmicpython-book/.
`BASE_PATH` должен начинаться и заканчиваться `/`. Значение одинаковое для
сборки и предпросмотра; на обычном домене используется `/`.

В репозитории подготовлен `.github/workflows/pages.yml`. В GitHub выберите
**Settings → Pages → Source: GitHub Actions**, затем отправьте код в `main`
(или измените ветку в workflow). Workflow получает путь сайта из configure-pages,
собирает и публикует `dist/client/`. Файл `.nojekyll` создаётся автоматически.

## Проверки

```sh
pnpm build
pnpm typecheck
pnpm test
pnpm exec playwright install chromium
pnpm test:browser
```

Для системного Chromium, например на NixOS:

```sh
CHROMIUM_PATH=/path/to/chromium pnpm test:browser
```

Браузерные проверки сравнивают вид до hover с исходной HTML-страницей на desktop
и mobile (за исключением нового переключателя темы), проверяют замену/возврат слова,
сдвиг соседнего текста, регистр, место для курсора, контекст, тему и касания,
навигацию, гидратацию и чтение без JS. Проверки файлов обходят ссылки и ресурсы
всех глав. Для проверки сборки в подпапке передавайте тот же `BASE_PATH` тестам.

## Устройство

`scripts/prepare-content.mjs` во время сборки применяет правки, переписывает
локальные ссылки и выбирает словарь для каждой главы. Создаются отдельные
маршруты TanStack Start, каждый со своим лениво загружаемым содержимым.
В браузер не попадает весь словарь или вся книга сразу. Исходные текстовые узлы
сохраняются без дополнительных обёрток. При наведении DOM Range находит слово
и его положение в абзаце. После выбора контекстного значения слово временно
заменяется обычным inline-элементом; браузер сам пересчитывает переносы строк.
Один обработчик на страницу, не чаще одного обновления на кадр, без React-рендера
на каждое движение мыши. Запросы к серверу перевода,
ключи API и серверная база данных не нужны. Оригинальные аналитика и Disqus
не подключаются.

Сгенерированные маршруты и `src/generated/` не редактируются и не коммитятся.
Обычная сборка не скачивает книгу, шрифты или словарь: все входные данные локальны.

Источники, авторы, лицензии и описание изменений: [content/SOURCES.md](content/SOURCES.md).
